Minified bytes are the ruler here, and the zip is not proportional

This page measures the minified bundle ( B), because that is the last stage where a byte can be traced to a line of source. The zip is of that, but compression is not uniform — repeated, predictable text nearly vanishes, so cutting it saves less than the chart implies.

Measured case: renaming GLSL identifiers took 1,918 B off this chart and 80 B off the zip, because the long repeated names were exactly what the packer was already good at. Treat a cell's area as where to look, then verify the real saving with npm run build.
